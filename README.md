# Hat Yai Flood Watch

เว็บติดตามสถานการณ์น้ำท่วมและข้อมูลช่วยเหลือสำหรับหาดใหญ่และจังหวัดสงขลา รองรับภาษาไทย อังกฤษ และจีน ใช้งานได้ทั้งมือถือและคอมพิวเตอร์ พร้อม PWA และธีมสว่าง/มืด

## ความสามารถ

- แสดงระดับน้ำ สถานีตรวจวัด แนวโน้ม และระดับเฝ้าระวังบนหน้าแดชบอร์ด
- ค้นหาสถานี ดูข้อมูลใกล้ตำแหน่งปัจจุบัน และดูสถานีบนแผนที่
- พยากรณ์ฝนรายชั่วโมงและรายวันจากกรมอุตุนิยมวิทยา
- ดูภาพ CCTV และอัปเดตประกาศเตือนภัย
- ค้นหาและดูสถานะศูนย์พักพิงบนแผนที่
- ส่งรายงานน้ำท่วมพร้อมภาพถ่าย และช่วยยืนยันรายงานจากผู้ใช้งานใกล้เคียง
- จัดการศูนย์พักพิงและประกาศผ่านหน้าผู้ดูแล
- สมัครรับการแจ้งเตือน Push สำหรับระดับน้ำ ฝนตกหนัก และประกาศจากผู้ดูแล
- ดูหน้านโยบายความเป็นส่วนตัว ข้อกำหนดการใช้งาน และเครดิต

## ความต้องการเบื้องต้น

- Node.js รุ่น 18 ขึ้นไป
- npm
- บัญชี Upstash Redis สำหรับเก็บข้อมูลเมื่อ deploy
- โทเคน API ของกรมอุตุนิยมวิทยา หากต้องการใช้หน้าพยากรณ์และข้อมูลฝน

## เริ่มใช้งานในเครื่อง

ติดตั้งแพ็กเกจ:

```bash
npm install
```

คัดลอกไฟล์ตัวอย่างการตั้งค่า แล้วแก้ `.env.local` ตามต้องการ:

```bash
cp .env.example .env.local
```

บน Windows PowerShell ใช้คำสั่ง:

```powershell
Copy-Item .env.example .env.local
```

เริ่มเซิร์ฟเวอร์พัฒนา:

```bash
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) ระบบจะพาไปหน้า `/th` โดยอัตโนมัติ

ต้องการใช้ข้อมูลจำลองแทนข้อมูลสถานีจริง ให้ตั้งค่าใน `.env.local`:

```env
MOCK=1
```

## การตั้งค่า

ดูรายการตัวแปรทั้งหมดและคำอธิบายใน [.env.example](./.env.example)

| ตัวแปร | จำเป็นเมื่อ | รายละเอียด |
| --- | --- | --- |
| `MOCK` | ทดลองหน้าจอแบบออฟไลน์ | ตั้งเป็น `1` เพื่อใช้ข้อมูลสถานีจำลอง |
| `THAIWATER_URL` | เปลี่ยนแหล่งข้อมูลระดับน้ำ | ไม่ตั้งจะใช้ endpoint ค่าเริ่มต้นของ ThaiWater |
| `PROVINCE_CODE` | เปลี่ยนจังหวัดของสถานี | ค่าเริ่มต้น `90` คือจังหวัดสงขลา |
| `TMD_TOKEN` | ใช้หน้าพยากรณ์และกราฟฝน | ขอรับโทเคนจาก [กรมอุตุนิยมวิทยา](https://data.tmd.go.th/nwpapiinfo/) |
| `ADMIN_PASSWORD` | ใช้หน้าผู้ดูแล | ตั้งรหัสผ่านที่คาดเดายาก แล้วเข้า `/th/admin` |
| `ADMIN_SECRET` | ต้องการแยก secret สำหรับเซ็นคุกกี้ | ไม่ตั้งจะใช้ `ADMIN_PASSWORD` |
| `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` | เก็บข้อมูลบนระบบ deploy | ใช้ Upstash Redis; หากไม่ตั้ง ระบบจะใช้ไฟล์ในโฟลเดอร์ `data/` |
| `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` | ส่ง Push notification | สร้างด้วย `npm run vapid` |
| `VAPID_SUBJECT` | ตั้งข้อมูลผู้ส่ง Push | ใช้รูปแบบ `mailto:you@example.com` |
| `CRON_SECRET` | เรียกงานตรวจระดับน้ำเพื่อส่ง Push | กำหนดค่าสุ่มที่คาดเดายาก และตั้งค่าเดียวกันใน cron provider |
| `OPERATOR_NAME`, `CONTACT_EMAIL` | แสดงข้อมูลผู้ให้บริการ | ใช้ในหน้านโยบาย ข้อกำหนด และเครดิต |

## การจัดเก็บข้อมูล

เมื่อไม่มีการตั้งค่า Upstash Redis ข้อมูลจะถูกเก็บเป็นไฟล์ใน `data/` ซึ่งเหมาะสำหรับการพัฒนาในเครื่องเท่านั้น ตัวอย่างเช่น ประกาศใน `data/notices.json`, ศูนย์พักพิงใน `data/shelters.json` และรายงานใน `data/reports/`

บนแพลตฟอร์ม deploy ที่ระบบไฟล์ไม่ถาวร ให้ตั้ง `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` เพื่อเก็บประกาศ ศูนย์พักพิง รายงาน และข้อมูลที่เกี่ยวข้องให้คงอยู่หลังการ deploy

## ตั้งค่า Push notification

1. สร้าง VAPID keys:

   ```bash
   npm run vapid
   ```

2. ตั้ง `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY` และ `VAPID_SUBJECT` ทั้งในเครื่องและใน environment ของระบบ deploy
3. ตั้งค่า Upstash Redis สำหรับเก็บรายการอุปกรณ์ที่สมัครรับการแจ้งเตือน
4. สร้างค่า `CRON_SECRET` แล้วตั้งค่าในระบบ deploy และ cron provider
5. ตั้ง cron ให้เรียก `GET /api/cron/alerts` พร้อม header `Authorization: <CRON_SECRET>` ประมาณทุก 5 นาที

ใน repository มี GitHub Actions workflow ที่ `.github/workflows/alerts.yml` ซึ่งทำงานทุก 5 นาที ต้องกำหนด GitHub Actions secrets ชื่อ `SITE_URL` และ `CRON_SECRET` ก่อนใช้งาน หรือเลือกใช้ cron provider อื่นที่รองรับช่วงเวลาตามต้องการ

การเรียกครั้งแรกจะบันทึกระดับน้ำปัจจุบันเพื่อเริ่มติดตาม และยังไม่ส่งแจ้งเตือนระดับสถานี หลังจากนั้นจะแจ้งเมื่อระดับสถานีสูงขึ้น โดยมีช่วงพักการแจ้งซ้ำ 3 ชั่วโมง ส่วนฝนคาดการณ์ตั้งแต่ 30 มม. ใน 3 ชั่วโมงจะแจ้งไม่เกินหนึ่งครั้งต่อ 3 ชั่วโมง

ทดสอบได้ที่ `/th/alerts` โดยยินยอมและเปิดการแจ้งเตือนก่อน แล้วกดปุ่มทดสอบ การทดสอบในเครื่องต้องใช้ HTTPS หรือ `localhost`; บน iPhone ต้องเพิ่มเว็บลงหน้าจอโฮมและใช้ iOS 16.4 ขึ้นไป

## แหล่งข้อมูลและข้อควรทราบ

- ระดับน้ำมาจาก endpoint สาธารณะของ ThaiWater ซึ่งไม่ได้ระบุว่าเป็น API ทางการ ควรตรวจสอบเงื่อนไขการใช้งานและขออนุญาตเจ้าของข้อมูลก่อนเปิดใช้งานจริง
- สถานีที่ไม่มีระดับตลิ่ง ข้อมูลไม่ครบ หรือข้อมูลเก่ากว่า 3 ชั่วโมงจะแสดงเป็นไม่มีข้อมูล
- เกณฑ์ `WATCH` และ `HIGH` กำหนดไว้ใน `lib/status.ts` ควรให้ผู้เชี่ยวชาญหรือผู้รู้พื้นที่ตรวจสอบก่อนนำไปใช้ประกอบการตัดสินใจ
- การพยากรณ์อากาศต้องมี `TMD_TOKEN`; หากไม่มี ระบบจะไม่สามารถแสดงข้อมูลพยากรณ์จากกรมอุตุนิยมวิทยาได้
- ข้อมูล CCTV ดึงจาก Hatyai City Climate และแคชไว้ 5 นาที ควรตรวจสอบสิทธิ์และเงื่อนไขการนำภาพมาแสดง พร้อมระบุเครดิตตามที่แหล่งข้อมูลกำหนด
- แผนที่ใช้แผนที่ฐาน OpenStreetMap โปรดปฏิบัติตามนโยบายการใช้งานของผู้ให้บริการ และพิจารณาใช้บริการแผนที่ของตนเองเมื่อมีทราฟฟิกสูง
- รายงานจากประชาชนเผยแพร่ทันที ภาพจะถูกเบลอในเบราว์เซอร์ รายงานหมดอายุภายใน 24 ชั่วโมง และระบบซ่อนรายงานที่ถูกรายงานตามเกณฑ์ที่กำหนด
- หน้า privacy, terms และ credits ใช้ข้อมูลจาก `lib/legal.ts` โปรดกรอกข้อมูลผู้ให้บริการและช่องทางติดต่อให้ถูกต้อง และให้ผู้เชี่ยวชาญด้านกฎหมายตรวจทานก่อนเปิดใช้งานจริง
